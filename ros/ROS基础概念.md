# ROS基础概念



## 1. 基础架构

**node & package**

node类似于安卓系统的app, 每个node可以实现一定的功能

package是node的集合, 一个包有很多的节点,安装的时候也是以包为基础

一般说来, 每个传感器都会对应一些特定的节点



**topic & message**

是节点之间的通信

假设一个超声波传感器和一个马达之间要进行通信, 他们的节点已经设置好了,都安装在各自的包里面

他们之间的持续通信是topic,每次的通信信息就是message



假设有多个节点中进行通信, 比如有多个传感器节点, 有一个马达, 每个传感器单独开一个topic和马达进行通信即可

也可以有在一个话题下多个发布者, 一个订阅者, 但是同一时间只能有一个发布者



*消息的类型:* 发布者, 订阅者



**launch**

可以同时运行多个节点

*XML语法*: \<标记名称 属性名1 = "属性值" ...> 内容 </标记名称>

```XML
<标记名称开头> 
<标记内容1>
</标记内容1>
</标记名称开结尾>
```

> 作用是用来描述一个多层嵌套的数据结构

eg.

````XML
<阵容>
    <选手 名字 = "诺言" 英雄 = "花木兰"/>
    <选手 名字 = "梦泪" 英雄 = "韩信"/>
</阵容>
````

eg. 完成了多个节点的一个结构示例, 此后就可以利用launch文件进行统一启动多个节点

```xml
<launch>
    <node pkg = "sensor" type = "yao_node" name = "yao_node"/>
    <node pkg = "sensor" type = "tao_node" name = "tao_node"/>
<launch/>
```



***ros消息包分类***

**标准信息包：**std_msgs: 有基础类型，数组类型，结构体类型

**常用消息包：**common_msgs: 行为消息包， 几何消息包.......





**栅格地图**:

利用方格划分地图,并且填充色块模拟真实的地图,划分的方格越多越接近真实的,但是数据量也越大,所以需要设置一个合适的分辨率





**SLAM**:

全称是 同时定位与地图创建,可以用于建立栅格地图

原理就是一边找参照物,一边利用相同的参照物定位自己的位置,并且不断扩大建立特征地图

*视觉slam*:记录特征,比如物体的颜色形状等

*激光slam:*初始的栅格地图都是灰色,发射激光可以穿透的栅格标记为白色,没有穿透的标记为灰色,并且不断扩大扫描





**TF**

可以理解为坐标系变换,用机器人的坐标系和地图的坐标系进行转换

用于机器人定位,利用栅格地图定位.





**里程计**:

一种软件算法,可以作为slam的补充,在特征变化不明显时用于计算走过的距离,建立地图三



**navigation导航**:

全局地图,自我定位,动态局部地图,导航路线规划

*全局规划器*: 用于规划起点到终点的路线,一般有两种主流算法: 广度优先(可以规划最短线路)和深度优先算法(计算量较小但是路径不是最短的), ros中内置了三种全局规划

*AMCL(自适应蒙特卡洛定位算法)*:用于在已知地图中自我定位,利用了粒子滤波

*代价地图*:用于防止机器人撞墙,在地图上增加代价区域,让机器人不能进入该区, 分为全局代价地图(计算时间长,但是基本只是算一次)和局部代价地图(对小范围进行代价计算,实时计算)

*恢复机制*:当导航路线被障碍物阻挡导致规划失败,会尝试重新规划路线,(利用雷达旋转重新检测地图看能否有可通过的线路)若所有尝试都失败后会放弃任务



*局部规划器*:运动控制器,处理临时障碍物规划实际运动路线

DWA(动态窗口方法)规划器:分为两个部分:生成轨迹(通过机器人的物理参数进行预测轨迹)和挑选轨迹,挑选轨迹时会综合考虑和全局地图的贴合程度,距离障碍物的距离,距离终点的距离等因素,选择最好的路线

TED(时间弹力带)规划器





# 2. 运动控制

**矢量运动:**

以机器人底盘的中心点为零点作坐标系, 所有矢量运动都可以分解为三个方向的分运动

坐标系用右手坐标系统，x轴指向机器人的正前方



**旋转运动:**

建立的坐标系通上，右手握拳，大拇指指向机器人的坐标轴的正方向，其他四指的方向就是运动的正方向





## 3.设备

**激光雷达**：

通常安装在底盘的中部，有红外激光发射器和接受器，利用光速测算距离，并且可以旋转，一直检测周围障碍物的情况



**IMU**：

一种安装在内部的传感器，用于测算空间姿态，输出三个方向上的加速度，包括矢量加速度和旋转加速度



**相机**:

分为普通的彩色相机和具有立体感知能力的RGB-D相机,借助相机可以实现识别, 定位,三维建图等功能
