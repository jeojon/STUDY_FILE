# ROS基础概念



## 1. 基础架构

**node & package**

node类似于安卓系统的app, 每个node可以实现一定的功能

package是node的集合, 一个包有很多的节点,安装的时候也是以包为基础

一般说来, 每个传感器都会对应一些特定的节点



**topic & message**

是节点之间的通信

假设一个超声波传感器和一个马达之间要进行通信, 他们的节点已经设置好了,都安装在各自的包里面

他们之间的持续通信是topic,每次的通信信息就是message



假设有多个节点中进行通信, 比如有多个传感器节点, 有一个马达, 每个传感器单独开一个topic和马达进行通信即可

也可以有在一个话题下多个发布者, 一个订阅者, 但是同一时间只能有一个发布者



*消息的类型:* 发布者, 订阅者



**launch**

可以同时运行多个节点

*XML语法*: \<标记名称 属性名1 = "属性值" ...> 内容 </标记名称>

```XML
<标记名称开头> 
<标记内容1>
</标记内容1>
</标记名称开结尾>
```

> 作用是用来描述一个多层嵌套的数据结构



eg.

````XML
<阵容>
    <选手 名字 = "诺言" 英雄 = "花木兰"/>
    <选手 名字 = "梦泪" 英雄 = "韩信"/>
</阵容>
````



eg. 完成了多个节点的一个结构示例, 此后就可以利用launch文件进行统一启动多个节点

```xml
<launch>
    <node pkg = "sensor" type = "yao_node" name = "yao_node"/>
    <node pkg = "sensor" type = "tao_node" name = "tao_node"/>
<launch/>
```
